Olá! PHP é uma linguagem fantástica com inúmeros recursos nativos que facilitam e entrega alta performance. Uma dessas funções é a str_getcsv, responsável por ler um arquivo csv e converter seus valores em um array. O valor padrão é a barra invertida () Uma string vazia (“”) desabilita o mecanismo de escape.
